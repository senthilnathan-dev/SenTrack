# Code of Conduct

SenTrack is a small project that handles people's private information, so trust matters. We want contributing to be
respectful and productive for everyone, human or AI-assisted.

## What we expect
- Be kind and assume good intent. Disagree with ideas, not people.
- Be constructive: say what is wrong and, where you can, how to improve it.
- Respect privacy: never share anyone's personal or financial information, including your own, in issues, pull requests,
  screenshots or test data. Use made-up data.
- Credit others' work, and be honest about what you tested and what you did not.
- Accept review gracefully, and review gracefully.

## What we do not accept
Harassment, insults, discrimination, personal attacks, doxxing, sexual or violent content, spam, or deliberately misleading
changes (for example hiding a privacy-affecting change inside an unrelated pull request).

## Scope
This applies in the repository (issues, pull requests, discussions, reviews) and wherever someone represents the project.

## Enforcement
The maintainer may edit or remove comments, close issues or pull requests, and block people who break these rules.
To report a problem, email **libertariansenthil@gmail.com** with the link and a short description. Reports are handled privately.
